## 当前结论

- 两组增量实验都优于 `6058`，说明直接派生特征在强主线上仍然有额外信息量。
- `full_derived_ctx 6079` 是当前最优结果：
  - `RMSE` 最低
  - `MAE` 也同步更优
  - `R2` 最高
- 但提升幅度并不大，属于“小而真实的增益”，不是结构性飞跃。
- `spatial_context` 仍然是更值得保留的部分：
  - 相对 `6077`，`6079` 再次更好
  - 说明方向信息最有效的注入方式仍是“方向感知空间上下文”

## 当前风险、阻塞和下一步建议

- 风险：
  - 当前提升幅度较小，如果继续无限制扩特征，可能很快进入复杂度增加快于收益增加的区间。
- 阻塞：
  - 目前还没有更长训练或多随机种子的复现实验，因此还不能把这 `0.001~0.002` 级别增益当成最终定论。
- 下一步建议：
  1. 若只需要一个当前默认主线，优先采用 `6079 full_derived_ctx`
  2. 若要确认这类小增益是否稳健，再做：
     - `6079` 同配置多随机种子复现
     - 或适度延长训练 epoch
  3. 若后续想继续做物理增强，优先继续围绕 `spatial_context` 精修，而不是继续堆更多局地原始派生量
