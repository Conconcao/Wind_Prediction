## 当前结论

- 只加局地物理派生特征 `derived_core`，对 `hub_ws_only` 有轻微提升，但增益有限。
- 在 `derived_core` 基础上再加入方向感知空间上下文 `derived_ctx`，提升变得明确且稳定。
- `derived_ctx` 明显强于此前的“只加风向/偏航”路线，说明方向信息更应该体现在“上风向空间关系”里，而不只是节点自身角度特征。
- 但这两组实验都明显落后于 `6058`，说明：
  - `1min` 高频聚合特征仍然是当前最强的信息源之一
  - 塔架原值 + 15min 额外 SCADA + 1min 聚合的组合，信息量仍大于当前这批物理派生特征
